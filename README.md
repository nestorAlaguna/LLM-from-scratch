# 🧠 LLM from Scratch: Building a Language Model from the Ground Up

Implementation of a transformer-based language model inspired by Andrej Karpathy's tutorial. Focused on understanding core NLP concepts through minimalistic code.

## 📌 Project Overview

Objective:
Build a toy-sized LLM (Large Language Model) from scratch to learn:

    Transformer architecture (self-attention, feed-forward layers)

    Tokenization and text generation

    Training loops and loss optimization

Key Features:
✅ Pure Python/Numpy implementation (no PyTorch/TensorFlow)
✅ Character-level tokenization
✅ Multi-head self-attention and positional encoding
✅ Training on Shakespeare text corpus
